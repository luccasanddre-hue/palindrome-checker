# Palíndromo Checker

Aplicação web desenvolvida para verificar se uma palavra ou frase é um palíndromo.

## 🚀 Tecnologias
- HTML5
- CSS3
- JavaScript

## 📋 Funcionalidades
- Verificação de palíndromos
- Tratamento de espaços e caracteres especiais
- Interface simples e responsiva

## 🎯 Objetivo
Praticar lógica de programação, manipulação de strings e desenvolvimento front-end.
